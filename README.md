## Короткие ответы

1. Чем List отличается от массива и как узнать количество элементов списка?

Ответ: чтобы узнать кол-во элементов в Лист нужно использовать Count он работает так же как и Length для массива , лист отличается от массива тем что он динамический , его размер можно свободно менять.  У массива длина фиксируется при создание.

2. Чем отличаются Remove() и RemoveAt()?

Ответ: Remove() удаляет элемент по его значению и возвращает значение бул , а метод RemobeAt() удаляет элемент по индексу и не возвращает значение 

3. Почему для вставки допустим индекс Count, а для удаления — нет?

Ответ: Потому что при вставке индекс Count означает добавление элемента в самый конец списка, то есть на новую часть , а для удаления индекс должен указывать на уже существующий элемент
